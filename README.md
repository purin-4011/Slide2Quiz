# Slide2Quiz: แปลงสไลด์เป็นแบบทดสอบด้วย Gemini AI

แอปพลิเคชันสร้างแบบทดสอบจากรูปภาพสไลด์เรียนอัตโนมัติ โดยใช้ Gemini API ผ่าน Google Gen AI SDK เป็นการต่อยอดจาก Lab GSP1150

## ✨ ฟีเจอร์ที่นำมาใช้ (ตามข้อกำหนดของการบ้าน)
1. **Spec-Driven:** มีไฟล์ `SPEC.md` ออกแบบ Input/Output และพฤติกรรมก่อนลงมือโค้ด
2. **System Instructions:** กำหนดให้โมเดลรับบทบาทเป็นอาจารย์มหาวิทยาลัยผู้เชี่ยวชาญ เพื่อให้ข้อสอบมีความถูกต้องทางวิชาการ
3. **Structured Output (JSON):** ใช้ `response_schema` และ `Pydantic` บังคับให้ AI คืนค่ากลับมาเป็น JSON ตามรูปแบบที่กำหนด เพื่อให้นำมาแสดงผลหน้าเว็บได้โดยที่โครงสร้างไม่พัง
4. **Multimodality (Image):** ส่ง Input รูปภาพเข้าไปให้ Gemini ตีความข้อความและเนื้อหาจากสไลด์
5. **Multi-turn chat (โจทย์เสริม - DETERMINATION):** เพิ่มระบบแชทจำลองติวเตอร์ เพื่อให้ผู้ใช้แชทถาม AI เจาะลึกเกี่ยวกับข้อสอบที่เพิ่งถูกสร้างขึ้นมาได้

## 🌡️ การตั้งค่า Temperature
- **Temperature = 0.2**
- **เหตุผล:** การสร้างข้อสอบต้องการ **ความถูกต้องของข้อมูล (Factual Accuracy)** สูงมาก คำตอบต้องอ้างอิงจากเนื้อหาในสไลด์อย่างเคร่งครัด การตั้งค่าต่ำจะช่วยควบคุมไม่ให้ AI ออกนอกลู่นอกทาง (Hallucinate) ลดการแต่งเติมข้อมูล หรือสร้างโจทย์ที่ไม่ได้อยู่บนสไลด์
